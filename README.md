# Weather Now 🌤️

A responsive weather application built with **HTML, CSS, and JavaScript** that displays real-time weather information using the **Open-Meteo API**. Users can search for any city, view current weather conditions, browse hourly and 7-day forecasts, and switch between different measurement units without making additional API requests.

## Live Demo

- **Live Site:** https://sibo02.github.io/Weather-app/
- **Repository:** https://github.com/sibo02/Weather-app

## Features

- 🔍 Search weather by city name
- 🌡️ Real-time current weather
- 🕒 Dynamic hourly forecast
- 📅 7-day weather forecast
- ☀️ Automatic weather icons based on live conditions
- 🌍 Date updates based on the selected city's timezone
- 🌡️ Temperature conversion (°C ↔ °F)
- 💨 Wind speed conversion (km/h ↔ mph)
- 🌧️ Precipitation conversion (mm ↔ in)
- 📱 Fully responsive layout for desktop and mobile

## Built With
